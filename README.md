# Hi, I'm Osman 👋

I'm a Business Informatics student at WU Vienna interested in data science, machine learning, and the questions we can answer with data. My projects range from predicting chess outcomes to exploring urban flood risk and fine-tuning language models.

## Featured projects

- ♟️ **[Predict the Unpredictable](https://github.com/OsmanTuerkmen/chess-outcome-prediction)** — Exploring whether in-game data can predict chess outcomes. The analysis uses more than 130,000 Lichess games and considers engine evaluations, time pressure, player ratings, and machine learning models.
- 🌍 **[Flood Risk Modelling](https://github.com/OsmanTuerkmen/Floodrisk-project)** — A team project from WU Vienna's Data Science Lab exploring how satellite imagery, elevation, rainfall, and map data can support flood risk analysis.
- 🧠 **[Emotion Detection with DistilRoBERTa](https://github.com/OsmanTuerkmen/Large-Language-Model-Finetuning)** — Fine-tuning a Transformer model to classify emotions in English text and comparing its performance with a pretrained baseline.
