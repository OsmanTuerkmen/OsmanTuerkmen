## About me

Outside of university and work, I build projects that mix statistics, maps, machine learning, and software.

## 🚀 Selected projects

### [Signly](https://github.com/OsmanTuerkmen/signly) · Hackathon

Built during a hackathon, Signly is a browser prototype that recognizes 12 isolated ASL signs. Hand and pose landmarks feed a temporal model running locally in the browser, so camera frames stay on the device. We kept the vocabulary focused and the demo honest about its limits.

**Stack:** React · TypeScript · MediaPipe · ONNX Runtime Web

### [Flood Risk Project](https://github.com/OsmanTuerkmen/Floodrisk-project) · WU × infrared.city

In WU Vienna's Data Science Lab, our team explored urban flood susceptibility together with infrared.city. We combined satellite imagery, elevation, rainfall, and map data; my focus was geospatial analysis and features such as vegetation, built-up area, and terrain slope.

**Stack:** Python · R · Remote sensing · Geospatial analysis

### [Predict the Unpredictable](https://github.com/OsmanTuerkmen/chess-outcome-prediction) · Chess analytics

I used more than 130,000 Lichess games to estimate in-game win probabilities. The project combines engine evaluations, player strength, and time pressure to understand what shifts the odds while a game is still in progress.

**Stack:** R · Lichess API · Stockfish · Statistical modeling
